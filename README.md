# Web Crawler TISS

Projeto desenvolvido em **Groovy**.

O projeto realiza buscas e downloads de arquivos do padrão **TISS da ANS**, além de consultar o histórico das versões.

## Tecnologias

* Groovy
* Gradle
* Jsoup
* HTTPBuilder-NG
* Java 8

## Execução

```bash
./gradlew run
```
